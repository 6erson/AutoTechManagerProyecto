Propósito y arquitectura

Sistema de taller para administrar clientes, vehículos, servicios, personal, inventario, órdenes, presupuestos y pagos. La interfaz oscura se organiza en cuatro secciones. Se separan presentación, negocio, datos y modelos; las operaciones de SQL usan parámetros y SwingWorker.

SQL Server contiene claves y restricciones, tres procedimientos, dos vistas y auditoría por trigger. El presupuesto conserva precios históricos, los consumos se procesan mediante transacciones y los pagos no superan el saldo.

Se implementaron la reparación básica y la sustitución de motor de una Hilux 2015. El cambio valida compatibilidad y registra series, autorización, responsables, actividades, destino del retirado, pruebas y garantía.

Validación

34 comprobaciones de integración aprobadas en una base aislada, incluyendo rollback de inventario y concurrencia en consumos y pagos. Las capturas usan datos de prueba. El precio 9999 del aceite es una modificación deliberada para comprobar la conservación del precio de órdenes anteriores.

Las evidencias y autorizaciones se guardan como texto. El documento de cobro es un comprobante interno imprimible, sin JasperReports.
